# RGB Color Cube Explorer

An interactive 3D RGB color-space visualizer built with **Three.js**. It renders a cube of sampled RGB colors, lets you orbit through the color space, inspect colors by hovering or clicking, search for a HEX value, and copy selected colors for use in design or development work.

## Features

* Interactive 3D RGB color cube
* Orbit, zoom, and pan camera controls
* Hover to preview colors
* Click to lock a selected color
* HEX, RGB, and HSL readouts
* Copy selected HEX value
* Search for a HEX color and jump to the nearest sampled color
* Random color selection
* Auto-rotate mode
* Adjustable RGB sample resolution
* Adjustable cube size
* Axis legend for red, green, and blue directions
* Responsive full-screen interface
* Modern glass-style UI overlay

## Demo Concept

The scene represents RGB color space as a 3D cube:

* **X axis**: Red channel
* **Y axis**: Green channel
* **Z axis**: Blue channel

Each small cube represents one sampled RGB color. For example:

* Low red, low green, low blue appears near black.
* High red, high green, high blue appears near white.
* High red only appears red.
* High green only appears green.
* High blue only appears blue.

## Requirements

You only need a modern web browser.

The project loads Three.js and OrbitControls from CDN:

```html
<script src="https://cdn.jsdelivr.net/npm/three@0.132.2/build/three.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/three@0.132.2/examples/js/controls/OrbitControls.js"></script>
```

No build step, package manager, or local server is required for the basic version.

## Quick Start

1. Save the file as `index.html`.
2. Open `index.html` in a browser.
3. Drag to rotate the scene.
4. Scroll to zoom.
5. Hover or click a cube to inspect a color.

## How It Works

### Scene Setup

The app creates a Three.js scene with:

* A perspective camera
* A WebGL renderer
* OrbitControls
* Ambient and point lighting
* A group containing all color cubes
* A raycaster for mouse picking

### Color Cube Generation

The color cube is generated by looping over red, green, and blue sample values:

```js
for (let r = 0; r < resolution; r++) {
  for (let g = 0; g < resolution; g++) {
    for (let b = 0; b < resolution; b++) {
      // Create cube at RGB coordinate
    }
  }
}
```

Each cube receives a color based on its normalized RGB position:

```js
const color = new THREE.Color(
  r / (resolution - 1),
  g / (resolution - 1),
  b / (resolution - 1)
);
```

### Color Picking

The app uses `THREE.Raycaster` to detect which cube is under the pointer:

```js
raycaster.setFromCamera(pointer, camera);
const intersects = raycaster.intersectObjects(app.cubes, false);
```

When a cube is selected, the app updates:

* Color swatch
* HEX value
* RGB value
* HSL value
* Selection outline

### HEX Search

When a user enters a HEX value, the app compares that target color against every sampled cube color and selects the closest match using RGB distance.

```js
const distance =
  Math.pow(color.r - target.r, 2) +
  Math.pow(color.g - target.g, 2) +
  Math.pow(color.b - target.b, 2);
```

## Customization

### Change the Default Resolution

Find this value in the app state:

```js
resolution: 10
```

Higher values create more colors, but also more cubes.

Example cube counts:

| Resolution | Total Cubes |
| ---------: | ----------: |
|          4 |          64 |
|         10 |       1,000 |
|         18 |       5,832 |

### Change Default Cube Size

Update:

```js
cubeSize: 0.46
```

Smaller cubes create more spacing between samples. Larger cubes make the color cloud appear denser.

### Change Spacing

Update:

```js
spacing: 0.72
```

This controls the distance between cube centers.

### Change the Background

The background is defined in the `body` CSS rule:

```css
background:
  radial-gradient(circle at top left, rgba(59, 130, 246, 0.35), transparent 34%),
  radial-gradient(circle at bottom right, rgba(236, 72, 153, 0.28), transparent 32%),
  #020617;
```

### Change CDN Version

The app currently uses Three.js `0.132.2`. You can update the CDN URLs if you want to use a newer Three.js version, but you may need to adjust OrbitControls loading depending on the version.

## Troubleshooting

### Cubes Render Black

This can happen when using `InstancedMesh` with instance colors in some Three.js versions or browser/GPU combinations.

The current version avoids that issue by using regular `THREE.Mesh` objects with direct `MeshBasicMaterial` colors:

```js
new THREE.MeshBasicMaterial({ color: color })
```

This makes colors render directly and avoids lighting or instance-color upload problems.

### Nothing Appears

Check that:

* You are connected to the internet so the Three.js CDN can load.
* The browser console does not show a script loading error.
* WebGL is enabled in your browser.
* The HTML file is saved correctly as `.html`.

### HEX Search Does Not Work

Use a valid six-digit HEX value:

```text
#7C3AED
7C3AED
#FFFFFF
000000
```

Three-digit shorthand values like `#fff` are not currently supported.

### Performance Is Slow

Lower the sample resolution. The total number of cubes grows quickly because the app renders:

```text
resolution × resolution × resolution
```

For example, resolution `18` creates `5,832` cubes.
